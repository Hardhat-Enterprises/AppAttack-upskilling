## 1. Initial Upskilling Resources for on-boarding Juniors

For on-boarding juniors that wish to do pen testing you will be required to have done a minimum amount of upskilling before you can begin pen testing.

### 1.1 Minimum Pentesting Upskilling

Ideally the minimum requirement to begin pen testing is that of completing all of the free modules in the Jr Penetration Tester course at [Tryhackme](https://tryhackme.com), (Note: You will have to create an account in order to access the free modules).

The free Jr Pen Tester Modules to complete are as follows: 

(Note: That list is subject to change depending on what is available)

* **Offensive Security Intro** 
* **Defensive Security Intro**
* **Search Skills**
  
* **Guided Pentest: Web**
* **Guided Pentest: Infrastructure**
  
* **Passive Reconnaissance**
* **Active Reconnaissance**
  
* **Nmap Live Host Discovery**

* **Content Discovery**
  
* **Burp Suite: Repeater**

* **SQL Injection Introduction**
* **CSRF Introduction**
  
* **Understanding Vulnerability Databases**
* **Vulnerability Scanning Tools**
* **NoScope: Finding RCE**
* **CVE-2026-46300: Fragnesia**
* **CVE-2026-42945: Nginx Rift**

* **OWASP Top 10 2025: IAAA Failures**
* **OWASP Top 10 2025: Application Design Flaws**
* **OWASP Top 10 2025: Insecure Data Handling**

* **Phishing Basics**
* **Hydra**
  
* **Metasploit: The Basics**

* **Host-Server Configuration Reviews**
* **Linux Privilege Escalation: Enumeration**

* **Intro to AD Authentication**
* **Intro to AD Breaching**
* **AD: Basic Enumeration**
  
* **Wireless Security**
* **DevSecOps Basics**
  
* **Python: Core Concepts**

* **Writing Pentest Reports**
* **Re-Testing**

It should be made clear that this is quite a lot to get through and you probably don't have to do ALL of the modules, but it is best to get through as many as possible as you have a fair amount of time, pen testing generally doesn't start till week 4 and onward.

### 1.2 Basic Understanding of Latex

Code Review Reports, Penetration Test Reports and Final Reports are handled using LaTeX, thus you will need to learn know how to use LaTeX if you haven't already been using it.

Resources to help you learn LaTeX and compile vulnerability reports can be found in the [Latex-Guide](../guides/Latex-Guide/latex-guide.mdx)
